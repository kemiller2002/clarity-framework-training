## Implementation implications for this site

1. **The kit is well built but has never been delivered**: no session data, feedback or outcome measures; the only planned measure is same-day self-report and the evaluation form is listed as missing. Add a 30/90-day behavioural follow-up (decisions recorded, triggers checked) before running any pilot.
2. **No certification.** The training roadmap's "No certification without use" rule is supported by the evidence; the April manifest's recommendation to create a completion certificate/badge contradicts the site's own "No certification or badges" promise (CON-K-001).
3. **Reconcile vocabulary** across the site, facilitator guide, participant packets and talks (three core sequences, two evidence vocabularies, five product names). The site's session model does not match the framework workflow (CON-A-014).
4. **Legal basis**: the site is MIT-licensed while binder pages say "internal use" and copyright is personal; resolve before any licensing.
5. **Recommended first training product** (per combined strategy v2): a paid one-day in-house pilot on the client team's own decisions, with 30/90-day behavioural follow-up, run as the parallel signal alongside the first service wedge — not a public course and not yet the two-day $20k session.
6. **Hygiene**: identical `README.md`/`readme.md` collide on case-insensitive filesystems; README begins mid-document; navigation differs across pages despite README claim; privacy page references a form that does not exist.
